# Local GLB integration contract

`src/model-assets.ts` exports `loadLocalModel(options)`. Merely importing it does not request missing files. The caller supplies only verified local paths, requested standing height in world metres, observed front yaw and optional animation GLBs from the same chosen character skeleton.

The loader preserves the full skin hierarchy using `SkeletonUtils.clone`, places an orientation/normalization wrapper around it, centres the model in X/Z and puts its rest-pose minimum Y at ground level. Actor position and bearing belong on the returned `root`; authored collision and permission state stay in simulation code. The returned metadata lists actual clip names/durations/tracks, skin count, bones, original size and applied scale. None of these infers rights, animation meaning or a fulfilled rig requirement.

After actual GLB inspection, map exact animation names to idle/walk/run/carry states. Call `playClip(exactName, fadeSeconds, speed)` only when state changes; it returns false for missing clips. Call `update(deltaSeconds)` while action is running and zero while paused. The mixer is rooted at the unchanged skin hierarchy; crossfades preserve joint animation. Root-motion tracks must be inspected after export; any removal must target the actual observed root node, not all position tracks.

Badge, backpack and ordinary carried inventory can use actor-space sockets in canonical world metres via `createSocket`. Its optional third argument is an observed runtime bone name; it reparents the canonical socket while preserving size/position, so badge/backpack/cargo can follow joint motion without changing the source rig. Keep their visibility tied to authoritative equipment/cargo state. Where an actual carry clip offers a suitable hand bone, `getBone(exactName)` exposes that bone for a verified attachment; source scale and bone transform must be measured before mounting inventory there. Do not modify skeleton node names or discard joints to align a mesh.
